Ce qui trompe le plus souvent

  • Caractères qui se ressemblent : "1" pour "l", "0" pour "o", "rn" pour "m"
  • Sous-domaines trompeurs : paypal.securite-connexion.com — le vrai domaine est securite-connexion.com, pas paypal.com !
  • Extensions différentes : .ch vs .com vs .info
  • Mots ajoutés : ecole-geneve-connexion.ch au lieu de ge.ch

La bonne méthode

Dans une adresse comme https://compte.exemple.paypa1-secure.info/login, le vrai domaine est toujours le dernier "mot.extension" juste avant le premier / — ici paypa1-secure.info, pas paypal. Tout ce qui vient avant (même si ça contient "paypal") est juste un sous-domaine que n'importe qui peut choisir librement.

Le réflexe

En cas de doute, ne jamais cliquer sur le lien reçu — retaper l'adresse connue directement dans le navigateur, ou passer par les favoris déjà enregistrés.
