C'était un faux message d'alerte — technique appelée le scareware.
Ce genre de fausse alerte ("7 virus détectés !") apparaît en général dans une pub, une fenêtre pop-up, ou une page web piégée. Elle n'a aucun accès réel à ton ordinateur — un site web ne peut pas scanner tes fichiers. Le nombre de "virus" est juste écrit à l'avance dans le code, comme ici : <span id="nb-virus">7</span>.

Le but est de te faire paniquer pour que tu cliques sur "Nettoyer maintenant" — ce clic mène généralement à télécharger un vrai logiciel malveillant (déguisé en "antivirus"), ou à une page qui demande ta carte bancaire pour un faux abonnement.

Même cliquer sur "Ignorer" n'aurait rien changé ici — dans cette démo, aucun des deux boutons n'envoie ou ne télécharge quoi que ce soit.

Le problème

Un navigateur web n'a pas accès à l'antivirus installé sur ton ordinateur, ni à tes fichiers. Aucune page web ne peut légitimement "scanner" ta machine.

Comment reconnaître une fausse alerte

🚩 Signaux d'un scareware
- Urgence extrême, compte à rebours, clignotement - Impossible de fermer la fenêtre normalement - Un site web qui prétend "scanner ton PC" - Design qui imite Windows/macOS mais pas exact
✅ Bon réflexe
Fermer l'onglet (pas juste la pop-up) via le gestionnaire de tâches si besoin. Ne jamais télécharger le "nettoyeur" proposé. Utiliser uniquement l'antivirus déjà installé sur l'appareil.

Les règles à retenir

1. Un vrai antivirus s'exécute comme un programme installé, jamais comme une page web.
2. Aucun site ne peut scanner les fichiers de ton ordinateur depuis le navigateur.
3. Face à une urgence fabriquée ("agis maintenant !"), le bon réflexe est justement de ne rien précipiter.
4. En cas de doute, fermer l'onglet et vérifier avec l'antivirus réel de l'appareil.

🔬 La preuve, en direct

Une page web ne peut techniquement voir un fichier de ton appareil QUE si tu le choisis toi-même dans une fenêtre de sélection — jamais toute seule, jamais en scannant ton disque. Essaie :

C'est tout ce qu'une page web peut obtenir — le nom et la taille d'un seul fichier, et seulement parce que tu l'as choisi explicitement dans cette fenêtre système. Aucun site ne peut lister ou lire le reste de ton disque, ni "scanner tes virus" sans que tu choisisses activement chaque fichier un par un — ce que ferait un vrai antivirus, lui, en tant que programme installé avec des droits différents.
