Le problème

Il suffit aujourd'hui de quelques secondes d'audio (une story, une vidéo publique) pour qu'un outil d'IA imite convaincant la voix de quelqu'un. Le ton paniqué et l'urgence achèvent de convaincre, même quand "la voix" semble parfaite.

La meilleure protection : un mot de code en famille

❌ Sans mot de code
"Maman, j'ai eu un accident, envoie vite de l'argent, je t'expliquerai après !" → Impossible de vérifier vite, la panique pousse à agir sans réfléchir.
✅ Avec un mot de code convenu à l'avance
"Dis-moi le mot de code de la famille." → Un clone vocal ne le connaît pas. Silence ou mauvaise réponse = arnaque confirmée en 2 secondes.

Les règles à retenir

1. Convenir en famille d'un mot de code simple, jamais partagé en ligne.
2. Face à une urgence financière par téléphone, toujours raccrocher et rappeler soi-même le numéro habituel.
3. Ne jamais envoyer d'argent sous la seule pression d'un appel, même si la voix semble juste.
4. Limiter les vidéos/audios publics avec sa voix aide, mais n'élimine pas le risque — le mot de code reste la vraie protection.
