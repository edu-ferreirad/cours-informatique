# S04E31 - Cartographie des blocs de redondance def valider_graphe_restauration(): # Liste de blocs d'index ordonnés noeuds = {"A": 12, "B": 8, "C": 15, "D": 5} ordre_execution = ["B", "D", "A", "C"] accumulateur = 0 for rang, cle in enumerate(ordre_execution): facteur = (rang + 1) if noeuds[cle] % 2 == 0: accumulateur += (noeuds[cle] // 2) * facteur else: accumulateur += (noeuds[cle] * 2) - facteur return accumulateur

💡 Indices d'analyse structurelle :
1. Au rang 0 (index de boucle 0, donc facteur = 1) : On évalue la clé "B". La valeur est 8. Elle est paire. Calculez (8 // 2) * 1.
2. Au rang 1 (facteur = 2) : Clé "D" (valeur 5, impaire). Appliquez l'alternative : (5 * 2) - 2.
3. Au rang 2 (facteur = 3) : Clé "A" (valeur 12, paire). Appliquez la formule paire associée au facteur 3.
4. Au rang 3 (facteur = 4) : Clé "C" (valeur 15, impaire). Résolvez l'expression impaire avec le facteur 4, puis faites la somme totale.
