# Analyseur de conformité structurelle de l'inventaire # Objectif : Déduire le hash d'intégrité système def calculer_checksum_registre(): # Liste ordonnée d'éléments obligatoires manquants ou présents selon l'Art. 12 nLPD # Chaque tuple représente : (Longueur_Champs, Poids_Reglementaire, Est_Actif) metadonnees_registre = [ (4, 12, True), # Identité du responsable (3, 8, True), # Finalités explicites (6, 15, False), # Catégories de données sensibles (5, 10, True) # Délais de conservation / Effacement ] # Règle d'évaluation complexe : # Somme cumulée de (Longueur_Champs * Poids_Reglementaire) uniquement si Est_Actif est True. checksum = sum(item[0] * item[1] for item in metadonnees_registre if item[2]) return checksum # Résultat attendu en entrée de console d'intégrité pour valider la souche.

Aide à la Réconciliation — Les 3 Piliers

1. Pilier Informatique : L'intégrité structurelle des données d'inventaire est assurée par l'application de masques de validation ou de checksums calculés sur des propriétés booléennes filtrées de listes ou de dictionnaires complexes.

2. Pilier Juridique : La tenue d'un registre des activités de traitement est une obligation légale explicite en droit suisse de la protection des données (sauf dérogation pour les PME à faible risque) — retrouvez le numéro de l'article de la nLPD qui l'impose. Le traitement doit par ailleurs s'appuyer sur des motifs justificatifs clairs : consentement exprès, intérêt légitime prépondérant, ou obligation légale stricte.

3. Pilier Forensics : La comparaison d'empreintes cryptographiques uniques (telles que produites par l'algorithme SHA-1 ou SHA-256) permet de certifier instantanément qu'un composant système de journalisation ou un fichier de configuration réglementaire n'a subi aucune altération malveillante.
