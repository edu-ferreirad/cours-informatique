MATRICE D'INTERDÉPENDANCE ALGORITHMIQUE

Les interrupteurs de flux vidéo sont obfusqués au niveau de l'infrastructure logicielle par une fonction d'exclusion logique XOR. Pour révoquer une caméra illicite sans faire planter le système d'audit, vous devez résoudre l'évaluation de routage suivante avant de cliquer sur les flux vidéo de la grille :

# COMPOSANT DE SÉCURITÉ : verification_matrice.py # Objectif : Déterminer la séquence exacte d'atténuation. def verifier_coherence(): # Déclaration des masques d'états binaires pour l'administration état_systeme = 0b1111 masque_legal = 0b1001 # Canaux légaux requis par la sécurité physique # Le masque d'alerte identifie les flux intrusifs par opération XOR flux_intrusifs = état_systeme ^ masque_legal # Rappel d'interprétation binaire : # Bit 3 (poids 8) : TX-04 | Bit 2 (poids 4) : RF-99 # Bit 1 (poids 2) : RF-12 | Bit 0 (poids 1) : TX-88 # Un bit à 1 dans 'flux_intrusifs' désigne un flux violant la nLPD à révoquer d'urgence. return bin(flux_intrusifs)

Indice Forensics : Résolvez l'opération binaire issue du script Python ci-dessus. Les deux bits positionnés à `1` vous indiqueront précisément quels TECH_ID (parmi TX-04, RF-99, RF-12, TX-88) constituent une infraction de surveillance comportementale active.
