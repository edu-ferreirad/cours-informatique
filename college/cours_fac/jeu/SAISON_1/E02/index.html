ZURICH-800 [ 4. RETOUR AU MENU PRINCIPAL ]
1. Informatique

Les balises <script> servent à insérer du code JavaScript dans une page.

2. Juridique

La modification illicite de données informatiques est réprimée par un article du Code pénal suisse voisin de celui sur l'accès indu (Art. 143) — celui-ci porte sur la détérioration, et non la simple consultation, de données.

3. Forensics

Cette technique consiste à injecter du code <script> malveillant dans une page web pour détourner son contenu. Son nom commence par "Cross-Site" — cherchez l'acronyme à 3 lettres utilisé en cybersécurité.
